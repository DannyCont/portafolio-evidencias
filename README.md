Portafolio web responsivo elaborado con HTML, CSS y JavaScript para presentar mi formación y proyectos.

## Perfil

Soy estudiante de TSU en Desarrollo de Software Multiplataforma en la Universidad Tecnológica Fidel Velázquez. Me interesa construir soluciones web, móviles y videojuegos.

- [FlexiAlmacén](https://github.com/DannyCont/sistema-inventario-microservicios) — sistema de inventario con roles, productos, movimientos y alertas.
- [Inventia](https://github.com/CarlosN225/Inventia-App-Escritorio) — aplicación para administrar inventario, usuarios y movimientos.

## Tecnologías

JavaScript, PHP, Kotlin, GDScript, HTML, CSS, SQLite, MySQL, MariaDB, Git, GitHub, Android Studio, Jetpack Compose, Godot y Docker.

## Ver el sitio

Abre `index.html` en un navegador. Para publicarlo con GitHub Pages, abre **Settings → Pages** y selecciona la rama  main y la carpeta **/(root)**.

La foto usa el avatar público de GitHub. El correo no se publica en esta versión.
